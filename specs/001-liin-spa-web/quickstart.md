# Quickstart: Liin Spa Web Application

## Requirements
- Node.js >= 18 (Current environment has Node v24.14.0)
- npm >= 9 (Current environment has npm 11.9.0)

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Launch Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

3. **Production Build**:
   ```bash
   npm run build
   ```

## Demo Accounts & Role Switcher
The app features a top-bar **Quick Role Switcher** to experience all RBAC facets in one click:
- **Admin**: Full access to all screens, financial P&L, system config, global staff commissions.
- **Receptionist / Cashier**: Front desk access: Booking Timeline, POS Billing with VietQR, Customer Check-in.
- **Technician / KTV**: Operational access: My treatment schedule, treatment check-in & before/after log, personal commission earnings.
